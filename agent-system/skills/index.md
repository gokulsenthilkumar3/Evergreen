# EverGreen skills

Focused cards share related concerns; taxonomy IDs remain individually traceable.

| Skill | Trigger | Priority |
| --- | --- | --- |
| [Product and requirements](product/SKILL.md) | New feature, unclear request or changed acceptance criteria | Must-have |
| [Architecture and scale](architecture/SKILL.md) | New module, shared data ownership or deployment topology change | Must-have |
| [Business UX and accessibility](ux/SKILL.md) | Workflow, navigation, form or dashboard change | Must-have |
| [React data flows](frontend/SKILL.md) | Query, mutation, route or staff/public screen change | Must-have |
| [Nest API contracts](api/SKILL.md) | Endpoint or business mutation change | Must-have |
| [Ledger and database integrity](data/SKILL.md) | Schema, stock, invoice, payment, cancellation or migration work | Must-have |
| [Identity and security boundaries](security/SKILL.md) | Auth, session, permissions, public API or dependency change | Must-have |
| [Privacy, compliance and legal evidence](privacy/SKILL.md) | Personal data, retention, export, tax/provider or licensing change | Must-have |
| [English and Tamil workflows](localization/SKILL.md) | New visible text, locale formatting or print changes | Should-have |
| [Performance and capacity](performance/SKILL.md) | Slow dashboard, large inventory or increased site/tenant load | Should-have |
| [Critical-path verification](quality/SKILL.md) | Feature, bug fix or release candidate | Must-have |
| [Delivery and release engineering](release/SKILL.md) | CI change, release candidate, hosting or installer work | Must-have |
| [Reliability and observability](operations/SKILL.md) | Health, logging, alert, scheduled job or incident work | Must-have |
| [Backup and disaster recovery](recovery/SKILL.md) | Migration, cutover, release or recovery drill | Must-have |
| [Documentation and developer setup](documents/SKILL.md) | Workflow, service URL, configuration or generated document change | Must-have |
| [Dependency and maintenance hygiene](dependencies/SKILL.md) | Dependency update, technical debt or framework change | Must-have |
| [Business reporting and optional forecasting](analytics/SKILL.md) | KPI, report, baseline forecast or AI proposal | Should-have |
| [Desktop and platform support](desktop/SKILL.md) | Installer, preload/IPC, updater, local backend or offline change | Must-have |
| [External integration contracts](integrations/SKILL.md) | Payment, accounting, tax, email or device provider integration | Should-have |
| [Team, cost and stakeholder decisions](governance/SKILL.md) | Roadmap, release risk, budget or cross-team dependency | Should-have |
| [Agent planning, memory and evaluation](agent/SKILL.md) | Any multi-step maintenance task or agent-system change | Must-have |
