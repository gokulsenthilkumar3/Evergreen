# Authored design system

Paper #F2EDE1, warm stock #E8DFCB, ink #1A1712, indigo #243E5C and madder #8B3A2A. Running heads, margin notes, numbered technical figures, input/output/status tables and a bibliographic apparatus establish a document rhythm.

Typography uses the Literata family when installed, then Georgia and Times New Roman. No font file was downloaded or bundled in this iteration; exact Literata typography remains a follow-up. Arial is reserved for controls and small apparatus. Headings avoid repeated italic last words. Photographs and customer deployments have not been invented.

Responsive layouts switch at 1250, 960 and 620 px. Small screens replace sticky storytelling with a manual stepper; wide tables retain horizontal scrolling. All main content is visible before script execution. Contact links, figures and the static 60-position hall remain in HTML. Form previews use textContent, not HTML interpretation.

Motion pause, text view, prefers-reduced-motion, prefers-contrast and A4 print styles are included. Figures are decorative or captioned; the optional canvas has an equivalent SVG and keyboard record selector. Modal records use the native dialog element and restore triggering focus. Control labels, selected tabs and errors are available to assistive technology.

Automated DOM checks do not establish visual quality, screen-reader usability, print pagination or GPU performance. Verify these on representative devices before public promotion.
