# ReAuthored motion handoff

The appended Motion Expansion in the supplied text supersedes its earlier motion section. This demo uses browser-native renderers rather than claiming a completed Adobe production.

| Layer            | Implemented behavior                                                                            | Fallback                                          |
| ---------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Feedback         | button, focus and copy/download states                                                          | visible status text                               |
| State            | fault cascade and three readings, layer changes, dialog entry, ticket changes                   | immediate state updates                           |
| Chapter entry    | one-shot figure strokes, heading settling, table rows and printed records                       | readable initial HTML                             |
| Scroll narrative | 900vh desktop native sticky sequence, seven selectable records                                  | mobile / motion-paused step buttons               |
| Ambient          | one margin thread                                                                               | paused while hidden, motion paused or hall active |
| CSS depth        | bounded table tilt and hover-only cover cutaway                                                 | static figure                                     |
| WebGL            | 60 low-poly bobbins, 2,880 triangles, one draw call, capped 30 draw updates/sec, DPR capped 1.5 | 60-position SVG plus keyboard selector            |
| Audio            | opt-in procedural ticks and success sound, lazy AudioContext                                    | silent by default; suspended on hiding / pause    |

The WebGL study pauses offscreen and when the page is hidden; reduced-motion and reported low-power devices retain SVG. Context loss or initialization failure exposes the static view. No frame-rate or benchmark result is asserted. Geometry is original and illustrative, not live telemetry.

The retained assets/evergreen-thread-study.jsx is an earlier eight-second Adobe starting composition. It is syntax checked, not executed. It does not represent the complete ReAuthored storyboard. No .aep project, rendered WebM, Lottie export, mill photography or claim of all 87 requested animation items is included. Those require a separately reviewed Adobe/art pipeline and real device rendering. Do not label native browser effects as Adobe-rendered assets.
